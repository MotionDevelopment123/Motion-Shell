# Motion-Shell

Motion-Shell is a script to replace the shell, aimed at turning Windows into a expierance closer to a dedicated gaming console.

#### Shell options currently available:
- Playnite
  - Playnite Fullscreen
  - Playnite with a splash video (Coming next)
- Steam (Coming Soon)
- Custom Shell (Coming Soon)
  - Allows you to select a custom .exe program that will launch as the shell and once closed will launch the Windows-Shell or alternative action such as signing out the account.

#### If you would prefer to implement this manually you can follow the guide in the Wiki here : [https://github.com/MotionDevelopment123/Motion-Shell/wiki/Manual:-Setting-Playnite-as-the-default-shell](https://github.com/MotionDevelopment123/Motion-Shell/wiki/Manual:-Setting-Playnite-as-the-default-shell)
